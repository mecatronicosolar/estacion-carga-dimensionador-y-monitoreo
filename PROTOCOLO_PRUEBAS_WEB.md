# Protocolo de pruebas web

Versión web-tg-2026.11.08.1. Fecha: 2026-11-08 (America/Bogota).

## Metodología reproducible

1. Verificar rama mejora-web-tg y huellas de fuentes en evidence/source-sha256.json. No publicar.
2. Iniciar servidor local: python3 -m http.server 8765 --bind 127.0.0.1.
3. Ejecutar node --test tests/unit.cjs tests/static.cjs y guardar salida en evidence/unit-static.log.
4. Con Playwright 1.62.1 disponible, ejecutar node tests/browser.cjs y node tests/boundaries.cjs. CHROME_PATH selecciona Chrome; TEST_URL cambia base y debe terminar en barra. Mantener logs originales.
5. Ejecutar python3 tests/generar_informe.py para reconstruir este informe y la matriz JSON. El generador no ejecuta ni aprueba pruebas por sí mismo.
6. Investigar fallos, corregir y repetir suites afectadas y regresión. No editar un estado para aparentar aprobación.

Motor: Node 24.22.1. Navegador ejecutado: Google Chrome 156.0.8078.80 en macOS. Matrices a 375, 768 y 1440 px. Evidencias antes: copia local sin modificar de la revisión base, escritorio1440 px. Evidencias después: copia modificada servida localmente, no sitio publicado. Capturas del dashboard en pruebas posteriores con red externa bloqueada deliberadamente.

Los fixtures de paneles/controladores/baterías son datos sintéticos coherentes para probar software, no especificaciones comerciales propuestas. B10 adelanta la edad de muestras dentro del contexto de prueba; no altera reloj físico ni espera un minuto real. B11 fuerza evento error y bloquea red para reproducir indisponibilidad; no prueba la caída de una estación real.

## Oráculos, tolerancias y estados

- Cálculos independientes: energía=P×t; corrienteDC=P/(Vη); nominal=V×Ah×ramas; útilDC=nominal×DoD; AC=útilDC×η; FV=Wh/(HSP×PR); caídaDC/AC mono=2ρLI/S. Trifásico equilibrado I=P/(√3 V FP).
- near usa tolerancia absoluta 1e-8 en unidades de cada caso por error de coma flotante en números moderados; no es precisión física. Presentación con 2 decimales implica redondeo ±0,005 unidades. Cantidades enteras, IDs y estados se comparan exactamente. La coherencia de placa P≈Vmp×Imp acepta 10% solo como control de entradas, no tolerancia metrológica.
- Aprobado: aserciones ejecutadas sin fallo. Fallido: no cumple aserción. Bloqueado: falta precondición externa. No ejecutado: planificado sin ejecución. Los casos bloqueados no se cuentan como aprobados.
- No hay prueba física, acreditación normativa, prueba completa WCAG ni aprobación del despliegue.
